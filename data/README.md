# Dataset

The project uses the publicly available Smart Logistics Supply Chain Dataset.

The dataset contains logistics-related variables such as:

- Inventory level
- Shipment information
- Traffic status
- Waiting time
- Asset utilization
- Demand forecast
- Logistics delay
- Environmental conditions

The dataset is used locally for exploratory data analysis and logistics KPI analysis.

## Dataset Source

Kaggle:

https://www.kaggle.com/datasets/ziya07/smart-logistics-supply-chain-dataset

## Local File

The dataset file used for the analysis is:

`smart_logistics_dataset.csv`

The CSV file is kept locally and is not included in the GitHub repository.
